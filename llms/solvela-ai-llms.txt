# Solvela

> Solana-native payment gateway for AI agents: an OpenAI-compatible LLM proxy at https://api.solvela.ai where every paid request is settled per call in USDC-SPL over the x402 protocol (HTTP 402 quote, signed payment, retry) with no API key and no account. 44 models from six upstream providers, 17 of them free; a trustless on-chain escrow scheme; a spend-down voucher channel; an A2A 0.3.0 agent card; a stdio MCP server; SDKs in TypeScript, Python, Go and Rust. Open source at github.com/solvela-ai/solvela.

Generated by API Evangelist on 2026-09-19 from the provider's public surface (method: generated). The provider publishes no llms.txt: /llms.txt returned 404 on api.solvela.ai, and solvela.ai / docs.solvela.ai return HTTP 402 DEPLOYMENT_DISABLED on every path, so the documentation links below point at the public source of the docs site.

## How to call it

- Free: POST https://api.solvela.ai/v1/chat/completions with {"model":"free","messages":[...]} — no header, no wallet; 5 requests/min per IP.
- Paid: send the same request without PAYMENT-SIGNATURE, read the 402 body (accepts[].amount in atomic USDC, pay_to, max_timeout_seconds 300), sign a USDC-SPL transfer on Solana mainnet, resend the byte-identical request with the signed payload base64-encoded in PAYMENT-SIGNATURE. Keep the X-Solvela-Receipt header from the response.
- Model ids are provider-prefixed (openai/gpt-4o, anthropic/claude-sonnet-4-5-20250929); aliases (sonnet, gpt5, haiku) and profiles (auto, eco, premium, free) are accepted in the model field.
- Rate limit 60/min per payer wallet; headers x-ratelimit-limit / -remaining / -reset (seconds) and retry-after on 429.
- Errors are {"error":{"type","message"}}; a 402 without a payment header is the x402 PaymentRequired object at the top level (detect by x402_version).
